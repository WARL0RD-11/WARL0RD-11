## 🎮 About Me

<img
align="right"
width="185"
src="https://avatars.githubusercontent.com/u/96386344?v=4"
alt="Nishant Verma"
/>

I am a **Gameplay Programmer** specializing in **Unreal Engine 5 and C++**, with a focus on building player-facing systems that remain modular, designer-friendly, performant, and maintainable throughout production.

My work spans gameplay architecture, interaction systems, combat, artificial intelligence, multiplayer replication, UI and input workflows, inventory and equipment systems, traversal mechanics, and runtime development tools.

* 🎓 Master’s in **Entertainment Arts and Engineering – Game Engineering** from the **University of Utah**
* 🎮 Worked on **Sticky Fingers**, a couch co-op heist game developed for **Nintendo Switch and Steam**
* 🏆 Contributed to **Pivot**, a **GDC 2026 Alt.Ctrl finalist**
* ⚔️ Building gameplay systems with **Gameplay Ability System**, replication, RPCs, and server-authoritative architecture
* 🤖 Experienced with **GOAP**, Behavior Trees, State Machines, AI Perception, navigation, and decision-making systems
* 🧩 Interested in the intersection of technical architecture, game feel, player agency, and rapid designer iteration
* 💼 Open to gameplay, systems, and AI programming opportunities

## 🚀 Selected Projects

### 🏎️ [DeathSentence](https://github.com/WARL0RD-11/DeathSentence)

**Vehicle Combat AI Prototype — Unreal Engine 5 and C++**

* Developed a custom Behavior Tree framework using Composite, Decorator, and Task nodes
* Built combat, roaming, strafing, pursuit, pickup, low-health, and low-ammunition behaviors
* Applied the Strategy pattern to targeting and pickup selection
* Implemented vehicle steering, throttle, braking, weapons, ammunition, damage, and recovery
* Generated reusable combat arenas through procedural layout systems

---

### 🤖 [TikkiTaka](https://github.com/WARL0RD-11/TikkiTaka)

**Top-Down Tank Combat and Runtime Level Editor — Unreal Engine 5 and C++**

* Implemented player controls through the Command pattern and Enhanced Input
* Developed GOAP-based AI for tanks and defensive towers
* Created world states, actions, goals, planning logic, and runtime planner debugging
* Built projectile weapons, target detection, line-of-sight checks, aiming, and recovery behaviors
* Created a runtime level editor with grid placement, configurable properties, save/load support, and patrol-route authoring

---

### 🧩 [Systems](https://github.com/WARL0RD-11/Systems)

**Reusable Gameplay Systems Sandbox — Unreal Engine 5 and C++**

* Built a data-driven inventory using the Type Object pattern
* Implemented reusable item behaviors for equipping, healing, and throwing
* Created a radial weapon wheel and quick-use workflows
* Separated item definitions from runtime behavior
* Explored extensible gameplay architecture without large conditional chains

---

### 🏗️ [Custom C++ Game Engine](https://github.com/WARL0RD-11/CustomCppGameEngine)

**Rendering, Tools, Asset Pipelines, Audio, and Gameplay**

* Extended an existing C++ engine with Direct3D and OpenGL rendering paths
* Implemented custom mesh and shader workflows
* Created a Maya plugin for exporting meshes into the engine
* Built reusable mesh, shader, audio, and AI asset builders
* Developed and integrated a custom engine-level audio system
* Integrated an externally developed AI system into the engine architecture
* Built multiple playable projects on top of the shared engine modules

---

### 🧠 [Gameplay Programming Patterns](https://github.com/WARL0RD-11/GPPatterns)

**Design Patterns Applied to Gameplay Problems**

Gameplay-focused implementations and experiments involving:

* Command
* Strategy
* Composite
* Observer
* State
* Type Object
* Component-based system design

The goal is not only to implement patterns, but to understand when each pattern improves extensibility, ownership, communication, and iteration inside a gameplay codebase.

---

### 🌐 [Blaster](https://github.com/WARL0RD-11/Blaster)

**Networked Multiplayer Gameplay — Unreal Engine and C++**

A multiplayer gameplay project focused on replicated combat, client/server communication, network-aware state, player interaction, and server-authoritative gameplay behavior.

## 🎯 Additional Game Work

### Sticky Fingers

A couch co-op heist game developed by a multidisciplinary team of 15 for Nintendo Switch and Steam.

My contributions included:

* Modular object interaction and grabbing systems
* Runtime input-device detection
* Cross-platform UI prompt switching
* Main menu, pause menu, settings, and level-selection workflows
* Save data, progression, and level-unlock systems
* Debugging utilities and milestone support
* Audio composition and implementation support

### Pivot

An alternative-controller game in which players physically move a couch-shaped controller to guide a virtual couch through an obstacle course while escaping a giant skull.

* Selected as a **GDC 2026 Alt.Ctrl finalist**
* Developed in a multidisciplinary student team
* Combined physical interaction, unconventional input, gameplay feedback, and spectacle-driven design
